
# Regina Student Life

A student resource website designed to help newcomers and students settle into life in Regina, Saskatchewan.

## About the Project

I created this project to make it easier for new students to find useful information and resources as they adjust to living in Regina.

## Live Website

https://reginastudentlife.netlify.app/

## Technologies

- HTML
- CSS
- JavaScript
- Netlify

## Development

This project was developed with assistance from AI tools, including Claude and Grok, alongside research from online articles and other resources.

## Purpose

To make settling into a new city easier by bringing practical student information together in one place.
